DUDAS COMUNES

Preguntas frecuentes sobre desarrollo a medida

¿En qué tecnologías construyen las aplicaciones web? +

Seleccionamos la tecnología según los requerimientos: frontend con React, Next.js o Vanilla JavaScript; backend con Node.js (Express), Python (FastAPI/Django) y bases de datos PostgreSQL o MySQL desplegadas en servidores Linux aislados.

¿Quién es el dueño del código fuente al terminar? +

El cliente es el propietario absoluto del 100% del código fuente, repositorio Git, esquemas de bases de datos y accesos al servidor. No retenemos propiedad intelectual.

¿Ofrecen soporte y mantenimiento post-lanzamiento? +

Sí. Todos los proyectos incluyen 30 días de garantía post-entrega sin costo adicional. Además, disponemos de planes de mantenimiento mensual preventivo y monitoreo 24/7 de servidores.
